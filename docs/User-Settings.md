# 用户设置

本页面列出影响 ParquetViewer 行为的用户可配置设置。

| 设置 | 说明 |
| ------------ | ---------- |
| Edit → Date Format | 更改日期值的显示与导出格式。<br> - **默认**：按用户本地日期格式显示。<br> - **ISO 8601**：使用格式 `yyyy-MM-ddTHH:mm:ss.FFFFFFF`。<br> - **自定义**：打开对话框，可配置任意自定义日期格式。 |
| Edit → Always Load All Records | 勾选后，每次打开 parquet 文件时，**显示行数**字段将初始化为加载全部数据所需的精确数量。 |
| Edit → Dark Mode | 在浅色 / 深色主题之间切换应用外观。 |
| Help → Language | 切换界面语言（多语言支持自 v3.5.1 起可用）。 |
| Help → About | 查看版本信息；可勾选 `Associate with .parquet files` 将 ParquetViewer 设为 .parquet 文件默认应用（需要管理员权限）。 |
