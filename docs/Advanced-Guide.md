# 高级指南

本页面面向高级用户，介绍 ParquetViewer 中一些不太显眼的功能。

# 列格式设置

可以控制 ParquetViewer 对某些数据类型的渲染方式。

## 日期 / 日期时间

默认情况下，日期时间值按用户本地格式渲染。但你可以通过 `Edit → Date Format` 选项全局控制渲染和导出时使用的格式。详见 [用户设置](User-Settings.md)。

## 浮点 / 双精度

右键点击该类型列的列头，会显示两种渲染选项：
- 科学计数法（默认）
- 十进制

科学计数法更精确且为默认选项。但在处理非常大/非常小的分数时，十进制渲染更易读：

注意：与日期格式不同，此格式更改不影响文件导出。

## 二进制数据

默认情况下，二进制数据以十六进制数字渲染，如 `A0-B1-C2-...`。右键点击此类列的列头，可从列表中选择不同的渲染方式。

默认选项包括：
- Hex（默认）
- ASCII（当字节可打印时优先显示文本，例如 `20250828`）
- Base64
- Size

此外还支持 Guid、IPv4、IPv6、Short、Integer、Long、Float、Double 等格式（按字节长度自动识别）。

注意：与日期格式不同，此格式更改不影响文件导出。

## 字符串（自动换行）

如果字符串列的某个可见单元格文本被截断，右键点击该列列头，会在上下文菜单中显示 **Wrap Text（自动换行）** 选项。

选择后会按需换行文本并扩展行高以完整显示。该选项仅在至少有一个可见单元格实际被截断时出现。

# 中键点击图片预览

如果 Struct 字段符合 [HuggingFace 图片格式](https://huggingface.co/docs/hub/en/datasets-image#parquet-format)，可以对字段执行鼠标**中键点击**，直接快速预览图片，跳过先打开 Struct 的步骤。

**HuggingFace 图片格式：**

```
{
    "bytes": ...
    "path": ...
}
```

# 冻结列

如果水平滚动条可见，右键点击任意列的列头可冻结该列及其之前的所有列。这样在 ParquetViewer 主网格中水平滚动时，这些列始终可见。

值得注意的是，列可以通过拖拽来重新排列。
